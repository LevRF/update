# Обновления

Публичный репозиторий, из которого программы получают обновления: сам софт, базы данных и любые другие файлы.
Один репозиторий обслуживает сразу несколько проектов.

> ⚠️ Репозиторий **публичный**: всё, что сюда выкладывается, может скачать кто угодно.
> Не публикуйте пароли, ключи, персональные данные и закрытые базы.

## Как это устроено

```
Публикуете релиз (тег genom-v1.2.0, файлы)  ──►  GitHub Action пересобирает manifest.json
                                                          │
Программа при запуске читает manifest.json  ◄─────────────┘
  ├─ версия новее локальной? → качает файлы из релиза
  ├─ проверяет SHA-256
  └─ раскладывает в папку программы (.zip распаковывается)
```

- **Проект** — любой набор файлов со своей версией. Софт и базы удобно вести как разные проекты
  (`genom` и `genom-db`), тогда базу можно обновлять, не перевыпуская программу.
- **Тег релиза** — `<проект>-v<версия>`: `genom-v1.2.0`, `genom-db-v2026.10.23`.
  Версия — числа через точку. Суффикс (`1.3.0-beta.1`) — пререлиз, в манифест он не попадает.
- **manifest.json** — генерируется автоматически, руками не править. В нём для каждого проекта
  последняя версия и список файлов с размером и SHA-256.

## Публикация новой версии

### Через сайт

1. **Releases → Draft a new release**.
2. **Choose a tag** → впишите новый тег, например `genom-v1.2.0` → *Create new tag*.
3. Перетащите файлы (zip с программой, `.db` и т. п.; до 2 ГБ на файл).
4. **Publish release**. Примерно через минуту обновится `manifest.json` (вкладка **Actions**).

### Скриптом

```powershell
$env:GITHUB_TOKEN = "<токен>"   # fine-grained token: только этот репозиторий, Contents: Read and write
.\tools\Publish-Release.ps1 -Project genom -Version 1.2.0 -Files .\build\genom-1.2.0.zip -Notes "Что нового"
.\tools\Publish-Release.ps1 -Project genom-db -Version 2026.10.23 -Files .\data\genom.db
```

## Подключение к программе

Скопируйте в программу один из клиентов из папки [`client/`](client/). Репозиторий `LevRF/update` в них уже прописан
(константа `DEFAULT_REPO` / параметр `-Repo`).

**Python** (только стандартная библиотека, Python 3.9+):

```bash
python updater.py genom --dir "C:\Program Files\Genom"
python updater.py genom-db --dir data --asset "*.db"
python updater.py genom --check
```

**PowerShell** (Windows PowerShell 5.1, ничего ставить не нужно):

```powershell
.\Update-App.ps1 -Project genom -Dir "C:\Program Files\Genom"
.\Update-App.ps1 -Project genom-db -Dir data -Asset *.db
.\Update-App.ps1 -Project genom -Check
```

Коды выхода: `0` — всё актуально или обновлено, `10` — есть обновление (режим проверки), `1` — ошибка.
Установленные версии хранятся в файле `.update.json` в папке установки.

Работающий `.exe` в Windows перезаписать нельзя, поэтому запускайте обновление **до** старта программы
(через ярлык-лаунчер или bat-файл), либо программа запускает апдейтер и закрывается сама.

Из своего кода можно читать манифест напрямую:
`https://raw.githubusercontent.com/LevRF/update/main/manifest.json`

## Структура

| Путь | Что это |
|---|---|
| `manifest.json` | Последние версии всех проектов (генерируется) |
| `.github/workflows/manifest.yml` | Action: пересобирает манифест при любом изменении релизов |
| `.github/scripts/build_manifest.py` | Сборщик манифеста |
| `client/updater.py`, `client/Update-App.ps1` | Клиенты обновления для программ |
| `tools/Publish-Release.ps1` | Публикация релиза из командной строки |
